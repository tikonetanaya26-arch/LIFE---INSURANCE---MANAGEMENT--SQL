#  Life Insurance Management System

> Turning insurance data into structured, searchable information using SQL Server.

##  Project Overview

This project is a SQL Server-based Life Insurance Management System
developed to manage and analyze insurance-related data such as:

👤 Customers  
📄 Policies  
💰 Premiums & Payments  
🏢 Branches & Agents  
📝 Claims  
👨‍👩‍👧 Beneficiaries  
📊 Policy Status History

##  Technology Used

- Microsoft SQL Server
- SQL Server Management Studio (SSMS)
- SQL

##  Example Stored Procedures

### 1. Get Customer Details
Retrieves customer information using Customer ID.

### 2. Get Policies of a Customer
Displays policies associated with a particular customer.

### 3. Get Policy Premium & Payment Details
Combines policy, payment and payment-method information.

### 4. Get Claim Details
Retrieves claim-related information.
